# Finance Website

Flask web app for tracking a simulated stock portfolio, based on Harvard CS50's Finance problem set.

## Structure

finance/application.py is the Flask app. finance/helpers.py holds shared helper functions such as stock lookups and formatting. finance/finance.db is the SQLite database. finance/templates and finance/static hold the page templates and static assets.

## Usage

Install dependencies with pip install -r finance/requirements.txt, then run the Flask app from the finance/ folder.
